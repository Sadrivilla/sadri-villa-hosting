# 🏡 Sadri Villa

Official web portal for Sadri Villa community management.

## Overview

Sadri Villa is a web-based platform designed to manage community members, announcements, galleries, activities, and administrative operations through a modern dashboard powered by Firebase.

## Live Website

https://your-domain.com

## Technology Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
- Firebase Hosting
- GitHub Actions (CI/CD)

## Deployment

This project is automatically deployed using GitHub Actions and Firebase Hosting.

### Deployment Workflow

1. Push code to Main Branch
2. GitHub Actions Triggered
3. Firebase Hosting Deployment Starts
4. Live Website Updated
